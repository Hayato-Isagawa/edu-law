# 0020. 初期スコープの拡張(教育機会確保法を 12 法令目として追加)と不登校場面の新設

- 状態: 採用
- 日付: 2026-06-17
- 関連 PR: TBD(`content/add-education-opportunity-act`)
- 関連 ADR: 0001(初期スコープ・ミラーブランド)・0003(法令コンテンツスキーマ)・0005(児童福祉法を 7 法令目として追加)・0018(場面軸 IA)

## 背景

ADR 0005 で児童福祉法を 7 法令目として追加し、schema の `order` 上限 `.max(N)` を ADR 駆動で拡張する前例を確立した。その後 8〜11 法令目(教育公務員特例法・地方公務員法・学校保健安全法・教育基本法)を加え、現在 11 法令。ADR 0018 では場面軸 IA に再編し、`src/data/scenes.ts` を正本として 4 カテゴリ 16 場面を定義した(`students` カテゴリは 5 場面)。

しかし**不登校**は学校現場の主要課題でありながら、次の 2 点が欠けていた:

- **場面が無い** — 場面軸 IA(ADR 0018)の入口から不登校に到達できない。教員は法令名を知らない限り関係法令へ辿り着けない。
- **根拠法が未収録** — 不登校対応の根拠法である**教育機会確保法**(平成28年法律第105号、正式名称: 義務教育の段階における普通教育に相当する教育の機会の確保等に関する法律)の独立ページが無く、国の基本指針・支援通知への整理された導線が無い。

教育機会確保法は不登校児童生徒等への教育機会の確保を国・地方公共団体の責務として定め、文部科学省の基本指針(平成29年3月31日)と「不登校児童生徒への支援の在り方について(通知)」(令和元年10月25日)が運用の中心である。これらは学校教育法の就学義務と表裏の関係にあり、現場照会頻度が高い。

ADR 0001 の初期スコープ記述は歴史的記録として保持し、本 ADR で「12 法令目として教育機会確保法を追加し、あわせて不登校場面を新設する」決定を独立して記録する。

## 検討した選択肢

- **A) 教育機会確保法を 12 法令目として追加し、`students` に不登校場面を新設**(採用) — schema を `.max(11)` → `.max(12)` に拡張、`order: 12` で新規法令ページを起こす。`school-refusal` 場面を追加し、教育機会確保法・学校教育法の両法令へ誘導する。法令一覧(`/laws/`)と場面軸(`/scenes/`)の双方から到達できる。
- **B) 場面のみ新設し、法令は e-Gov リンクのみで独立ページを起こさない** — 教育機会確保法の公式解説(基本指針・支援通知)を見出し整理して案内できず、本サイトの中核価値(「公式解説への入口」)が不登校領域で成立しない。
- **C) 法令ページのみ追加し、場面は新設しない** — 場面軸 IA(ADR 0018)の入口から不登校に到達できないままで、現場の困りごと起点の導線が確保されない。

## 決定

A 案を採用する。

### 具体的な変更

- `src/content.config.ts` の `order` 制約を `.max(11)` → `.max(12)` に拡張する(1 行のみ)。
- `src/content/laws/education-opportunity-assurance-act.md` を新規作成し、`order: 12` で配置する。タイトルは通称「教育機会確保法」とし、正式名称は `summary` と本文初出に併記する(ADR 0002 req#4 を充足)。公式解説 publisher は全て `mext`(ADR 0003 既存登録、`PUBLISHER_LABELS` で「文部科学省」に解決)。
- `src/data/scenes.ts` の `students` カテゴリ末尾に `school-refusal` 場面を追加する(5 → 6 場面、ADR 0018 の分割閾値 ≤6 の範囲内)。全体は 16 → 17 場面。
- `src/data/changelog.ts` に追加エントリを 1 件加える(ADR 0017、ユーザー価値のある変更)。
- ドキュメントの件数表記を追随させる: `README.md` / `CLAUDE.md`(11 → 12 法令、16 → 17 場面)、トップページ・法令一覧ページの「11 法令」表記。

### 公式解説の選定

文部科学省(`mext`)の以下 3 リソースを採用する(本 PR 起票前に `curl` で HTTP 200 とページ題を逐語確認):

1. 義務教育の段階における普通教育に相当する教育の機会の確保等に関する基本指針の策定について(通知) — 平成29年3月31日(`https://www.mext.go.jp/a_menu/shotou/seitoshidou/1384370.htm`)
2. 不登校児童生徒への支援の在り方について(通知) — 令和元年10月25日(`https://www.mext.go.jp/a_menu/shotou/seitoshidou/1422155.htm`)
3. 「教育機会確保法」って何?(リーフレット、PDF)(`https://www.mext.go.jp/content/20231018-mxt_syoto02-000021384_001010.pdf`)

ADR 0003 の `eGovUrl` 正規表現(`^https://laws\.e-gov\.go\.jp/`)および `officialExplanations[].url` 正規表現(`^https://[^/]+\.go\.jp/`)を満たす。`publisher: mext` は既存登録ゆえ新規追加は不要。

## 帰結

### 良い帰結

- 不登校に直面した教員が、場面(`/scenes/` の `students`)からも法令一覧(`/laws/`)からも、教育機会確保法の基本指針・支援通知に到達できる。
- 学校教育法(就学義務)との関連が法令ページ間で示され、ADR 0001 の「法令別ポータル」設計に沿う。
- schema の `.max(N)` を ADR 駆動で拡張する手順(ADR 0005 の前例)が再現され、以後の拡張手順が一貫する。

### トレードオフ / 既知のリスク

- 対象法令が 11 → 12 に拡張される。後続の追加ごとに ADR + schema 拡張の運用負荷が発生する(`order` を unique constraint 化する等の構造変更は今回行わない、最小変更原則)。
- `students` カテゴリが 6 場面に達し、ADR 0018 の分割閾値(≤6)の上限となる。次に `students` へ場面を追加する際はカテゴリ分割の要否を検討する。
- `school-refusal` 場面は教育機会確保法・学校教育法への一方向参照(ADR 0018)。法令 `.md` 側に逆タグ(逆方向クロスリンク)は持たせない(本 PR のスコープ外)。

## 撤回 / 再検討の条件

- 13 法令目を追加する場合は、本 ADR を参照しつつ新規 ADR を起こして `.max(N)` を再拡張する。
- `students` カテゴリに 7 場面目を追加する場合は、ADR 0018 の分割閾値を踏まえカテゴリ分割を検討する。
- 不登校ガイド(`/guides/`)を新規執筆する場合は別途判断する(本 ADR は法令ページ + 場面の追加に限り、ガイドはスコープ外)。
