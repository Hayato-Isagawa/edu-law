# 0011. 「子供への指導・対応」と「教師を守る」の 2 入口 IA(トップでの分岐)

- 日付: 2026-05-24
- ステータス: 撤回(0018 で上書き)
- 関連 PR: feat/two-entrance-ia

## 背景

ADR 0010 決定 4 と撤回再検討条件は、「子供向け / 教師向け」2 入口への正式分離を「教師側コンテンツが 2〜3 本たまった段階で別 ADR として検討する」と定めていた。

その後、教師側ガイドは保護者対応・教員のメンタルヘルスと休職復職・長時間労働と働き方改革の **3 本**に達し、発動条件を満たした。

現状、子供(児童生徒)への指導・対応に関わる法令と、教師自身を守る支援とが、トップページの場面一覧(`scenarios[]` 9 件)とガイド一覧(4 件)に混在している。ADR 0010 のトレードオフで「『何のサイトか』の輪郭が一時的にぼやける」と予見したとおりの状態であり、訪問者が自分の目的に合った入口を一目で選べない。

## 決定

### 1. 2 入口の定義と分類基準

サイトの導線を次の 2 つの入口で整理する。

- **入口A「子供への指導・対応」**: 児童生徒・教育活動をめぐる法令。`scenarios[]` の法令リンク 6 件(いじめ対応 / 教材コピー / 保護者からの開示請求 / 児童虐待の発見・通告 / 教員免許の確認・更新 / 体罰・懲戒の境界)と、その背後の 7 法令ページ。
- **入口B「教師を守る」**: 教師自身の立場・相談先に関わる公的支援(ADR 0010 決定 2 のスコープ)。`scenarios[]` のガイドリンク 3 件(保護者からの過剰な苦情・不当要求 / 教職員のメンタルヘルス・休職 / 教員の長時間労働・働き方改革)。

ガイド「日本の法令階層」は、どちらの入口にも効く前提知識として「読む前の基礎」に独立させる。

### 2. トップページでの分岐と 2 グループ表示

トップのヒーロー直下に 2 入口の選択を置き、場面一覧を入口 A・B の 2 サブセクションに見出し分けする。ガイド一覧も「読む前の基礎」「教師を守る」で見出し分けする。

### 3. 軽量実装に限定する

入口は独立ページにせず、トップとガイド一覧の表示グルーピングで表現する。

- 新規ページ・URL 変更はしない(既存の法令・ガイドの URL を保つ)
- グローバルナビ(ヘッダ・フッタ)は再編しない
- 分類はページやデータの永続属性にせず、表示側のグループ分けで持つ(ガイドは既存のベタ書き配列に表示用の区分を加えるに留め、collection 化しない)

## なぜこの判断にしたか

- **トップでの分岐にした理由:** ADR 0007 でトップを目次に位置づけている。16 ページ規模では、入口を独立ページにするとトップと役割が重複し過剰になる。トップで分岐を示し、その下で 2 グループに整理するのが、ADR 0010 のトレードオフが警告した「薄いうちの正式分離=過剰設計」を避けつつ目的を満たす右サイズである。
- **URL を変えない理由:** 既存の法令・ガイドページは一次資料への入口として被リンク・共有され得る。グルーピングは表示の問題であり、URL を動かす必要がない。リダイレクトや SEO の損失も避けられる。
- **ガイドを collection 化しない理由:** ガイドは 4 本で、トップとガイド一覧という 2 箇所でしか参照されない。スキーマと content collection を導入する便益より、ベタ書き配列に区分を足す方が変更が小さく読みやすい。

## トレードオフ — 「正式分離」としては軽い

- 結果: 各入口が独立した到達点(ページ)を持たないため、ADR 0010 が言う「正式分離」としては軽い構成に留まる。
- 受容理由: コンテンツ量に対して右サイズを優先する。入口ごとの本数が増えた段階で、入口ページ化を別 ADR で再検討できる(撤回再検討条件)。

## 不採用案

### 入口ページを 2 枚新設する

子供向け / 教師向けの入口ページを設けて関連法令・ガイドを集約する案。トップ(ADR 0007 の目次役)と内容が重複し、16 ページ規模には過剰。不採用。

### ガイドを content collection 化して区分を持たせる

`laws` と同様にガイドを collection 化し、frontmatter に入口区分を持たせる案。4 本に対してスキーマ導入は過剰で、ベタ書き配列に表示用区分を足せば足りる。不採用。

### グローバルナビを 2 入口に再編する

ヘッダ・フッタのナビを「法令一覧 / ガイド」から 2 入口に組み替える案。ナビは全ページ共通の安定要素であり、現状 3 項目で機能している。再編の便益が変更・検証コストを上回らないため不採用。トップでの分岐で導線を確保する。

## 検証

- `npm run check`: 0 errors / 0 warnings
- `npm run build`: 16 ページを維持(新規ページなし)
- `dist` grep: 2 入口アンカー(`#scenarios-child` / `#scenarios-teacher`)の出現、2 グループ見出し、場面一覧 9 件のリンクがすべて健在(URL 変更なし)、ガイド一覧の 2 グループ

## 撤回再検討条件

- いずれかの入口のコンテンツが 5 本を超えて肥大化した場合 → 入口ページ化(独立した到達点の新設)を別 ADR で検討する
- グローバルナビでの分岐が必要なほど入口の認知が課題になった場合 → ナビ再編を別 ADR で検討する

## スコープ外

- 入口の独立ページ化(将来フェーズ、撤回再検討条件)
- グローバルナビ(ヘッダ・フッタ)の再編
- 法令・ガイドの URL 変更
- `laws` collection の拡張・ガイドの collection 化
