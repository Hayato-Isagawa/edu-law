# 0012. 引用根拠を公共データ利用規約 第1.0版 へ移行

- 状態: 採用
- 日付: 2026-05-25
- 関連 PR: `feat/migrate-public-data-license`
- 関連: ADR 0002（引用ルールと運用ポリシー）の「政府標準利用規約 第 2.0 版の運用」節を supersede する

## 背景

ADR 0002 は、公式解説（文部科学省・文化庁・厚生労働省 等の PDF / HTML）の引用根拠として「政府標準利用規約 第 2.0 版」を採用していた。

週次リンクチェック（issue #57）で、サイトが参照していた規約 PDF `https://www.kantei.go.jp/jp/singi/it2/cio/dai55/siryou3-2.pdf` が 404 になっていることが判明した。調査の結果、これは単なる URL 移動ではなく規約の世代交代だった。

- 政府標準利用規約 第 2.0 版 は所管が内閣官房 IT 総合戦略室からデジタル庁へ移管され、現在は「（参考）」扱い・新規適用は非推奨
- 現行の標準は デジタル庁「公共データ利用規約（第 1.0 版）」（2024 年 7 月 5 日）。デジタル庁は「これまで政府標準利用規約や CC BY 4.0 等を適用してきたウェブサイト・オープンデータには、公共データ利用規約をご利用ください」と案内している
- 引用条件は実質同等（出典の記載・編集加工時の表示・第三者の権利の確認・国の標章等は規約の適用外・CC BY 4.0 と互換）

ADR 0002 の「撤回／再検討の条件」に「政府標準利用規約が改訂された場合は本 ADR を上書きする ADR を起票する」とあり、本 ADR がそれを履行する。

## 検討した選択肢

- **A) 政府標準利用規約 第 2.0 版 を維持し、リンクのみ生きた URL に差し替える** — デジタル庁が参考掲載する PDF（`assets` パス）に差し替える案。新規適用が非推奨の規約に留まり、`assets` パスは将来また 404 になりやすい。独立した安定ページもない
- **B) 公共データ利用規約 第 1.0 版 へ移行する** — 政府の現行・推奨規約に準拠。安定した公式ページ URL がある。引用条件は同等のため、運用の歯止め（ADR 0002 の 5 要件）はそのまま維持できる

## 決定

**B 案** を採用する。

- 引用根拠を「公共データ利用規約 第 1.0 版」へ統一する
- 公式ページ URL は `https://www.digital.go.jp/resources/open_data/public_data_license_v1.0`
- ADR 0002 §「政府標準利用規約 第 2.0 版の運用（規約 5 条件のサイト側実装）」を本 ADR で supersede する。条件は実質同等のため、ADR 0002 §「引用範囲遵守 5 要件」とサイト側実装（出典明示・編集加工注記・第三者権利確認・標章不使用・規約参照表示）はそのまま維持する
- 公共データ利用規約が CC BY 4.0 と互換である旨を `/about` の引用の根拠に明記する

### 影響範囲（本 ADR で更新するファイル）

- `src/pages/about.astro`（引用の根拠セクション）、`src/pages/index.astro`（編集方針）、`src/components/SiteFooter.astro`、`src/pages/laws/[slug].astro`、ガイド 7 本のフッター（引用の根拠リンクのラベル）
- `LICENSE` / `README.md` / `CLAUDE.md` / `CONTRIBUTING.md`
- 過去 ADR 0001 / 0002 / 0003 / 0007 の本文は不変とし、規約名の参照は本 ADR で上書きされたものとして読む

## 帰結

### 良い帰結

- 政府の現行・推奨規約に準拠し、リンク切れ（#57）が解消される
- 公式ページ URL が安定し、将来の 404 リスクが下がる
- 引用条件が同等のため、サイトの運用の歯止め（ADR 0002 の 5 要件）はそのまま機能する

### トレードオフ / 既知のリスク

- 規約名が複数のファイル・ドキュメントに分散しているため、移行時に表記の取りこぼしが起きやすい（dist の全文 grep で「政府標準利用規約」の残存ゼロを検証して担保する）

## 撤回 / 再検討の条件

- 公共データ利用規約が 1.1 / 2.0 等に改訂された場合（本 ADR を上書きする ADR を起票する）
- デジタル庁・各府省・e-Gov 運営側のいずれかから運用方針照会・是正依頼があった場合
- 著作権法 13 条 / 32 条の解釈に影響する判例・法改正が出た場合
