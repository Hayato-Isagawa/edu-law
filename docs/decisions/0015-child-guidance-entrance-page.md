# 0015. 「子供への指導・対応」入口の独立ページ化(2 入口の対称化)

- 日付: 2026-05-27
- ステータス: 採択
- 関連 PR: feat/child-guidance-entrance

## 背景

ADR 0013 は「教師を守る」入口を独立ページ `/protect-teachers/` 化する一方、子供入口は現状維持(トップ内アンカー `#scenarios-child` + 場面 6 件のインライン列挙)とし、教師=ページ / 子供=インラインの**非対称を意図的に許容**した(決定 3)。その撤回再検討条件に「**入口の非対称が利用者の混乱を生む場合 → 子供入口のページ化を別 ADR で検討する**」と定めていた。

その後、トップの 2 つの入口カードは見た目が同一(両方とも `→`)でありながら、子供入口=ページ内アンカーへのスクロール / 教師入口=ページ遷移と挙動が割れている点を、サイトオーナーが違和感として指摘した。これは ADR 0013 の発動条件に当たる。

あわせて姉妹サイト EduEvidence JP の実装パターンを調査した。同サイトのトップ(`src/pages/index.astro`)は **leaf コンテンツ(73 戦略のリスト)をインラインで長く積む**一方、ナビゲーション・ハブ(「悩みから探す」= concerns)は**独立ページ `/concerns/`** を到達点とし、トップには注目 4 件のプレビューカードのみを置いてページへ誘導している。すなわち family の規範は「leaf リストはインライン / ナビ・ハブは独立ページ + トップはプレビュー」という二段構えであり、`/protect-teachers/` はこの規範に沿った正しい実装で、子供入口だけが独立ページを欠いていた。

## 決定

### 1. 「子供への指導・対応」入口ページの新設

`/child-guidance/`(`src/pages/child-guidance/index.astro`)を新設し、子供入口の独立した到達点とする。

- スコープ説明(ADR 0011 の入口 A「児童生徒への対応の法的根拠」)+ 場面 6 件への導線で構成する
- 説明文はトップの子供セクションヘッダの既存コピーを流用し、「判断を示さず所管法令と公的情報の所在のみを示す」立場文を添える(自前解釈ゼロ)
- 場面の本文(`いじめ対応`〜`体罰・懲戒の境界` の 6 件、各 `summary`)は既存トップの記述を **verbatim で移設**し、新規の条番号・解釈は加えない

### 2. トップページの整理

- 入口カード「子供への指導・対応」のリンク先を、ページ内アンカー `#scenarios-child` から `/child-guidance/` へ変更する
- インライン `#scenarios-child` セクションをトップから撤去し、内容は新ページへ移す
- フロントマターの `scenarios[]`(全件 `group: "child"`)を削除する(セクション撤去で未使用になるため)。`LawRow` の import は `laws` / `highlights` 描画で引き続き使用するため残す

### 3. 入口の対称化

入口 A(子供)・入口 B(教師)をともに独立ページ(`/child-guidance/`・`/protect-teachers/`)とし、トップの 2 つの入口カードはいずれもページ遷移に統一する。ADR 0013 が許容した非対称を解消する。

### 4. 入口ページの行コンポーネント統一

両入口ページの一覧行を、行全体を単一リンクとするエディトリアル行 `src/components/EntranceRow.astro`(`href` / `title` / `description`)に統一する。`/protect-teachers/` の従来の「タイトル(`<h3>` 内リンク)+ 末尾『開く』リンク」という同一 href への 2 リンク構成を、行全体 1 リンクに是正する(重複リンクの解消はキーボード・スクリーンリーダー利用者の冗長な移動を除く a11y 改善でもある)。`/laws/` 等で使う番号付き `LawRow` とは用途が異なるため別コンポーネントとする。

### 5. ナビ・URL は不変

グローバルナビ(ヘッダ・フッタ)は再編しない。既存の法令・ガイドの URL は変えない。`/child-guidance/` はトップ入口カードとパンくずから到達する。

## なぜこの判断にしたか

- **子供入口をページ化する理由:** ADR 0013 の発動条件(非対称が混乱を生む)を満たした。加えて family 規範(EduEvidence `/concerns/`)がナビ・ハブの独立ページ化を標準としており、対称化は family との一貫性を高める
- **`/laws/` との重複懸念が解消された理由:** ADR 0013 が子供入口のページ化を見送った唯一の根拠は「子供入口は `/laws/` への場面ポインタで、ページ化すると重複する」だった。しかし EduEvidence は `/concerns/`(悩みレンズ)と戦略リストを**別レンズとして意図的に共存**させている。`/child-guidance/`(場面レンズ)と `/laws/`(法令レンズ)の共存は、むしろ family が意図したパターンであり、重複ではなく異なる入射角として許容される
- **トップから子供セクションを撤去する理由:** 到達点をページに一本化し、トップとページの二重掲載(ADR 0013 が教師側で避けた重複)を避ける。トップは法令リスト + Highlights で family 規範どおりの長さを保つ

## トレードオフ

- `/child-guidance/` と `/laws/` は対象法令が一部重なる。場面レンズ / 法令レンズの別面として許容する(EduEvidence `/concerns/` 先例)
- トップから場面 6 件のインライン一覧が消え、ファーストビュー直下の情報量は減る。入口カード経由の 1 クリックで到達できること、および family 規範(ハブはプレビュー+ページ)との整合を優先する

## 不採用案

### すべてをトップにインライン集約する(教師ページも畳む)

ADR 0013 を撤回し、教師 10 ガイド + 子供 6 場面をすべてトップにインライン化して両入口をページ内アンカーで対称化する案。トップの縦長自体は family 規範上許容範囲だが、その長さは **leaf リスト**から来るものであり、**ナビ・ハブをインライン化する点で EduEvidence `/concerns/` とは逆行**する。直近で構築した `/protect-teachers/`(10 ガイドの到達点)を畳み直すコストも伴うため不採用。

### スムーズスクロール / 矢印による挙動区別にとどめる

子供入口をインラインのまま、ジャンプを滑らかにする・入口カードの矢印を `↓`(ページ内)/ `→`(遷移)で区別する案。違和感の表層は緩和するが非対称は残り、family 規範との不整合も解消しないため不採用。

## supersede

- ADR 0013 **決定 3(子供入口は現状維持 — 非対称を許容)** を supersede する。ナビ・URL 不変、`/protect-teachers/` の方針、`/guides/` との役割分離など 0013 のその他の決定は維持する。

## 検証

- `npm run check`: 0 errors / 0 warnings
- `npm run build`: 24 → 25 ページ(`/child-guidance/index.html` 生成)
- `dist` grep: `/child-guidance/` に場面 6 件の `/laws/...` 内部リンク各 1・パンくず・末尾導線(`/laws/`・`/about/`)/ トップの子供入口カード `href="/child-guidance/"`・`id="scenarios-child"` の消失・教師入口カード `href="/protect-teachers/"` の健在 / `/protect-teachers/` の各行が単一リンク化(同一 href の重複 `<a>` の消失)/ sitemap に `/child-guidance/` の新 URL

## 撤回再検討条件

- いずれかの入口のコンテンツが薄いまま `/laws/` との重複が利用者にとって冗長と判断される場合 → 入口の統廃合を別 ADR で検討する
- グローバルナビでの分岐が必要なほど入口の認知が課題になった場合 → ナビ再編を別 ADR で検討する(ADR 0011・0013 撤回条件を継承)

- グローバルナビ(ヘッダ・フッタ)の再編
- 法令・ガイドの URL 変更、`laws` collection の拡張・ガイドの collection 化
