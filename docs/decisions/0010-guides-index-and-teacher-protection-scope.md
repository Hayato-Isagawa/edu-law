# 0010. ガイド一覧の新設と「教師を守る」スコープの追加

- 日付: 2026-05-24
- ステータス: 採択
- 関連 PR: feat/guides-parent-response

## 背景

EduLaw JP は当初「子供の指導の法的根拠」を整理することを中心に設計され、ガイドは「日本の法令階層」(`/guides/legal-hierarchy/`)1 本だった。ナビ(ヘッダ・フッタ)はこの単一ガイドへ直リンクしていた。

サイトの本義は `CLAUDE.md`・`docs/BRAND.md` が示す「教師の判断を法で固める」ことにある。これは子供の指導場面に限らず、教師自身が不当な要求から身を守る場面にも及ぶ。悪質な保護者クレームで休職に追い込まれる教師の現実を契機に、保護者からの過剰な苦情・不当要求に対する公的な支援と相談先の所在を集約する 2 本目のガイドを追加する。

ガイドが複数本になると、ナビが単一ガイドへの直リンクのままでは破綻する。また「教師自身を守る」観点をサイトのスコープに正式に含めるかは、コンテンツの方向性を左右する意思決定であり、記録を残さないと将来の追加・再編のたびに再議論となる。

## 決定

### 1. ガイド一覧ページの新設

`/guides/`(`src/pages/guides/index.astro`)を新設し、ヘッダ・フッタのナビは個別ガイドへの直リンクをやめて一覧へ向ける。

- 一覧は登録済みガイド(法令階層 / 保護者対応)をタイトル + 説明 + 導線で並べる
- ガイドが増えるたびにナビの直リンクを貼り替える運用は破綻するため、一覧を増分の受け皿とする

### 2. 「教師を守る」スコープの追加

サイトの対象を、従来の「子供の指導の法的根拠」に加えて「教師自身の立場・相談先に関わる公的支援の所在」へ拡張する。第 1 弾が保護者対応ガイドである。

- スコープは当面「保護者クレーム対応」に絞る(教員保護の体系化は将来フェーズ)
- 関連法令は身分保障系まで(地方公務員法・労働安全衛生法)。刑法など対抗・処罰を想起させる法令は含めない

### 3. 自前解釈ゼロの厳守(保護領域でも)

教師保護の領域でも、`CLAUDE.md`「設計の核」の自前解釈ゼロを崩さない。

- 対処法の良し悪しや「対抗手段」は一切判断・提示しない。示すのは公式情報(国・教育委員会・教職員支援機構・スクールロイヤー・自治体)の所在のみ
- 身分保障系法令は e-Gov 法令検索の本文への入口に留め、「安全配慮義務」等の法的概念ラベルは付けない(安全配慮義務は労働契約法 5 条・判例法理に由来し、公務員は別構成のため断定を避ける)

### 4. 将来の IA 再編

「子供向け / 教師向け」2 入口への正式分離は、教師側コンテンツが 2〜3 本たまった段階で別 ADR として検討する。今回は 1 本追加し、一覧でまとめる暫定構成とする。

## なぜこの判断にしたか

- **一覧を設ける理由:** 単一ガイドへの直リンクは 2 本目で破綻する。一覧はガイドの増分に耐え、ナビを安定させる。トップの法令目次化(ADR 0007)と同じく「増えるものは一覧で受ける」方針に揃える
- **教師保護をスコープに含める理由:** 「教師の判断を法で固める」本義は、指導の正当性を支えるだけでなく、教師自身が不当要求から身を守る局面にも及ぶ。現実の休職事例が動機であり、国(文部科学省)が働き方改革の柱として保護者対応支援を施策化している事実を確認できたため、所在の集約に踏み出す
- **保護領域でも自前解釈ゼロを崩さない理由:** 保護者対応は感情的・対立的になりやすく、サイトが対処助言や対抗手段を示すと中立性と安全性を損ない、誤った助言のリスクを負う。公式の場所を示すに徹することで、サイトの立場を一貫させる

## トレードオフ — スコープの輪郭が一時的に曖昧化

- 結果: 「子供の指導」と「教師保護」が同一サイトに混在し、「何のサイトか」の輪郭が一時的にぼやける
- 受容理由: 2 入口の正式分離はコンテンツが薄いうちに行うと過剰設計になる。トップの scenario とガイド一覧で導線を保ちつつ、教師側が 2〜3 本たまってから再編する方が確実
- ガイド一覧が 2 件だけだと薄いが、増分方針(決定 1)を先に確定する価値を優先する

## 不採用案

### 保護者対応を laws collection に入れる

保護者対応は単一法令に紐づかない横断テーマであり、`laws` schema(ADR 0003、`order` 最大 7・一次源限定)に適合しない。ガイドとして独立させる。

### 個別ガイドへの直リンクをナビに維持する

2 本目以降でナビの貼り替えが必要になり破綻するため不採用。一覧を経由させる。

### 対処法・テンプレ文例を掲載する

「こう言い返す」「この書式で記録する」等の実務助言は自前解釈ゼロ(ADR 0002 / `CLAUDE.md`)に反するため不採用。公式の所在提示に徹する。

## 撤回再検討条件

- 教師側ガイドが 2〜3 本たまった場合 →「子供向け / 教師向け」2 入口の IA 再編 ADR を起票(決定 4 の実行)
- 「所在の提示」を超える要望(対処助言・文例提供等)が優勢になった場合 → 決定 3(自前解釈ゼロ)の原則を別 ADR で再検討(ただし本義に関わるため慎重に)

## スコープ外

- 「子供向け / 教師向け」2 入口の正式分離(将来フェーズ、決定 4)
- `laws` collection の拡張(`order` 最大 7 の撤廃 / `.lg.jp` 自治体ドメインの許可)
- 刑法など対抗・処罰を想起させる法令
