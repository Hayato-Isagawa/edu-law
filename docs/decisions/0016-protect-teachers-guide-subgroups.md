# 0016. 「教師を守る」入口のガイドを性質別 3 グループに再編

- 日付: 2026-06-10
- ステータス: 採択
- 関連 PR: feat/protect-teachers-guide-subgroups

## 背景

「教師を守る」入口 `/protect-teachers/`(ADR 0013)のガイドは、ページ新設時の 6 本から 10 本に増えた(保護者対応 / メンタルヘルス / 公務災害 / 働き方改革 / 懲戒・分限 / 学校事故 / 妊娠・出産・育児 / 非正規教員 / 労働安全衛生 / カスタマーハラスメント)。一覧は作成順のフラット 1 リストで、各行のタイトルが長いこともあり、目的のガイドにたどり着くには 10 行を通読する必要がある。`/guides/` 一覧の「教師を守る」グループも同じ 10 本を同順で列挙しており、同じ課題を持つ。

ADR 0011 の再検討条件(入口のコンテンツが 5 本を超えて肥大化した場合 → 入口ページ化を別 ADR で検討)は ADR 0013・0015 の入口ページ化で消化済みであり、本 ADR は入口ページの**中**の一覧整理を扱う。

## 決定

### 1. 性質別 3 グループへの再編

「誰との / 何の問題か」を帰属基準として、ガイドを次の 3 グループで表示する。ガイドのタイトル・URL・説明文は変更しない(グループ見出しの追加と並び替えのみ):

| グループ | 帰属ガイド(表示順) |
|---|---|
| 保護者・外部への対応 | 保護者対応 / カスタマーハラスメント対策 / 学校事故の補償と責任 |
| 心身の健康と安全 | メンタルヘルスと休職・復職 / 公務災害 / 労働安全衛生管理体制 |
| 勤務条件と身分 | 働き方改革 / 妊娠・出産・育児との両立 / 非正規の教員 / 懲戒・分限処分 |

### 2. 両ページの同期(定義の正本は本 ADR)

`/protect-teachers/` と `/guides/` 一覧の「教師を守る」は同じグループ構成・同じ並び順で表示する。グループ定義・帰属の正本は本 ADR とし、変更は両ページを同一 PR で更新する。

- `/protect-teachers/`: 総称見出し「Guides — 場面別ガイド」をグループ見出し(h2)× 3 に置き換え、各グループを `EntranceRow`(見出し h3)で列挙する。見出し階層は h1 → h2 → h3 を保つ
- `/guides/` 一覧: 大見出し「教師を守る」(h2)は維持し、配下にサブ見出し(h3)× 3 を追加、ガイド行の見出しは h4 とする(「読む前の基礎」は h2 → 行 h3 のまま)

### 3. 今後の追加の運用と再検討条件

- 新規ガイドは原則 3 グループのいずれかに帰属させる。収まらない場合はグループ新設を本 ADR の改訂(または後続 ADR)で扱う
- 1 グループが 6 本を超えたら、グループの分割・再編を別 ADR で検討する(ADR 0011 の閾値運用を踏襲)

## なぜこの判断にしたか

- **性質別(誰との / 何の問題か)を選んだ理由:** 各ガイドの帰属が一意に決まりやすく、新規ガイドの追加先判断も明快。検討した状況軸(平時に備える / 事案発生時 / 手続き)は、メンタルヘルス(平時の体制でも事案後の支援でもある)等で帰属が解釈依存になり揺れる
- **3 / 3 / 4 の構成:** 既存 10 本が偏りなく収まり、各グループが一目で見渡せる量になる

## トレードオフ

- 作成順(時系列)の情報は一覧から消える。履歴は changelog と git が保持する
- グループ定義が 2 ページのフロントマターに重複する。データ共有化(`src/data/` への抽出)は現時点の 2 ページ・1 定義では過剰と判断し、正本を本 ADR に置く運用で同期する

## 不採用案

### 状況軸(平時 / 事案発生時 / 手続き)の 3 グループ

読者の置かれた状況で探せる利点はあるが、複数状況にまたがるガイドの帰属が解釈依存になり、追加のたびに判断が揺れるため不採用。

### 現状維持(フラット 10 本)

10 本はまだ通読可能だが、「教師を守る」系ガイドは今後も追加が見込まれ、いずれ再編が必要になる。本数がさらに増えてからの再編は利用者のリンク認知の組み替えコストが大きくなるため、現時点で整理する。

## 検証

- `npm run check`: 0 errors / 0 warnings
- `npm run build`: 29 ページ(ページ数不変)
- `dist` grep: 3 グループ見出しが `/protect-teachers/` と `/guides/` に各 1 / 両ページの `/guides/...` 内部リンクが全数残存(入口 10 本・一覧 11 本)/ 新しい並び順での出現 / changelog 反映

## 撤回再検討条件

- 1 グループが 6 本を超えた場合 → グループの分割・再編を別 ADR で検討する
- グループ分けが利用者の探索の妨げになっていると判断される場合(目的のガイドの帰属が直感に反する等)→ 帰属基準の見直しを本 ADR の改訂で扱う

## スコープ外

- `/child-guidance/`(子供入口)の再編 — 6 場面のフラットリストを維持する
- グローバルナビ(ヘッダ・フッタ)の再編、ガイドの URL・タイトル・説明文の変更
- ガイド定義のデータ共有化(`src/data/` への抽出)
