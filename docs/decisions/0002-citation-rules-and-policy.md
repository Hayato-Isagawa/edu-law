# 0002. 引用ルールと運用ポリシー

- 状態: 採用
- 日付: 2026-05-08
- 関連 PR: TBD(`feat/citation-rules-adr`)

## 背景

EduLaw JP の中核ポリシーは「自前の法解釈はしない、公式解説の見出し整理 + 公式 URL への誘導に徹する」(`CLAUDE.md`)。これを実際の運用で守るための技術的・運用的な歯止めを ADR レベルで明文化する必要があった。

ADR 0001 は「引用ルール ADR は別 PR で確定」「政府標準利用規約 + edu-watch ADR 0008 5 要件継承」を約束しており(本 ADR で履行する)、`CONTRIBUTING.md` も「具体的な引用ルール ADR は別途起票予定」と読者に約束済み。

引用元は性格の異なる 2 種類が混在する:

- **法令本文(条文)**: 著作権法 13 条で著作権の対象外。複製・改変ともに自由
- **公式解説(文部科学省・文化庁・厚生労働省 等の PDF / HTML)**: 政府標準利用規約 第 2.0 版が適用される。同規約の 5 条件(出典記載・編集表示・第三者権利確認・国家標章不使用・規約への参照)を満たせば、複製・翻訳・改変・商用利用ともに可能

姉妹サイト EduWatch JP は ADR 0008 で著作権法 32 条「引用」の枠組みに収まる 5 要件を採用済み。EduLaw JP も同じ運用基盤に揃えると、3 サイト共通で「出典明示・直リンク・編集者意見なし・誤り報告窓口」の運用骨格が一貫する。

## 検討した選択肢

- **A) edu-watch ADR 0008 をそのまま流用** — 引用元の性格(教育ニュース vs 法令解説)が異なるため、ニュース引用要件(「RSS 配信そのまま」「タイトル原文ママ」等)は edu-law では文脈不適合な部分がある
- **B) edu-watch ADR 0008 の 5 要件を edu-law 文脈に翻案 + 政府標準利用規約 5 条件を運用に落とす** — 姉妹サイト共通の運用基盤を維持しつつ、edu-law 独自の中核(自前解釈ゼロ)を明文化できる
- **C) 完全に別フレームワークを作る** — 姉妹サイト共通運用が崩れ、ADR 0008 を改訂したときの追従コストが上がる

## 決定

**B 案** を採用する。

### 引用範囲遵守 5 要件(edu-watch ADR 0008 の翻案)

EduLaw JP のすべての法令ページ・解説ページについて、以下を必須とする。

#### 1. 出典の明示

各法令ページに「出典」表示を本文外で固定する。

- 法令本文の場合: `出典: e-Gov 法令検索`(リンク先は該当法令の e-Gov ページ)
- 公式解説の場合: `出典: 文部科学省『○○解説』(取得日: YYYY-MM-DD)` の形式
- 公式解説 PDF の場合: 取得日に加えてバージョン情報(発行年月、改訂版番号)があれば併記

#### 2. 公式 URL への直リンク

法令本文・公式解説への遷移は、必ず以下のいずれかへの直リンクとする。

- e-Gov 法令検索(`https://laws.e-gov.go.jp/`)
- 文部科学省・文化庁・厚生労働省の公式ドメイン
- 内閣府・こども家庭庁等、関係省庁の公式ドメイン

第三者まとめサイト・SNS シェア用短縮 URL・リダイレクトラッパー・プロキシ経由のリンクは使わない。リンクは新しいタブで開き、`rel="noopener noreferrer"` を付与する(本リポジトリは `rehype-external-links` で自動付与済み)。

#### 3. 自前の法解釈を加えない

サイト本文に以下のような独自解釈を書かない。

- ❌ 「この条文は○○を意味する」
- ❌ 「現場では○○と運用される」
- ❌ 「裁判所は○○と判断する可能性が高い」
- ❌ 「したがって学校はこうすべきである」

許容するのは以下のような構造提示のみ。

- ✅ 「文部科学省『○○解説』第 3 章では、本条文に関して〜と説明されている(該当 PDF へのリンク)」
- ✅ 「第 ○ 条第 ○ 項 — e-Gov で本文を読む(リンク)」
- ✅ 公式解説の見出し構造を整理して並べる(本文は引用せず公式 PDF へ誘導する)
- ✅ 関連法令同士の参照関係を矢印で示す(解釈は加えない)

判断に迷う表現は `law@edu-evidence.org` への報告窓口で外部からの指摘を受け付ける(本 ADR §5)。

#### 4. 法令名・条文番号の改変禁止

法令の正式名称・条文番号・項番号・号番号は原文ママとする。略称(「いじめ防止法」「個情法」等)を使う場合は、各ページで初出時に必ず正式名称を併記する。

```markdown
✅ いじめ防止対策推進法(以下「いじめ防止法」)第 2 条
❌ いじめ防止法 第 2 条 (初出で正式名称併記なし)
```

#### 5. 誤りの報告窓口の明示

`law@edu-evidence.org` 宛に以下を報告できる旨を `/about` ページ(将来作成)に明記する。

- 公式解説リンクの誤り(リンク切れ・移動先誤り)
- 自前の法解釈が混入している箇所の指摘
- 条文の誤転記・条数の誤り
- 出典・取得日の表示漏れ

報告受領後、**24 時間以内** に該当箇所を訂正・削除・非表示にする(姉妹サイト edu-watch ADR 0008 と運用整合)。Email Routing は `運営専用アカウント` に集約され、休暇等で 24 時間以内対応が困難な期間は `/about` で告知する。

### 政府標準利用規約 第 2.0 版の運用(規約 5 条件のサイト側実装)

| 規約条件 | サイト側実装 |
|---|---|
| 出典の記載 | 本 ADR 5 要件 #1 で実装(本文外に固定表示) |
| 編集加工した場合の表示 | 公式解説を要約・抜粋した場合、近傍に「文部科学省『○○解説』を加工して作成」と注記 |
| 第三者の権利が含まれる場合の確認 | 公式解説中の図表・写真は二次利用可否が個別規定のため、当面は転載せず「公式 PDF をご確認ください」リンクのみとする |
| 国家標章等の使用禁止 | サイト UI で日本国紋章・各省庁ロゴ・国旗を装飾用途に使用しない |
| 規約への参照表示 | フッターまたは `/about` で政府標準利用規約 第 2.0 版へのリンクを表示する(`LICENSE` での記載とリンクの両方) |

### `lastVerified`(取得日)の運用予約

6 法令ページ実装(別 PR)時に、コンテンツコレクション(`src/content/laws/`)の frontmatter に `lastVerified: YYYY-MM-DD` を必須化する。

- 具体的な `content.config.ts` の Zod スキーマ定義は別 ADR(コンテンツスキーマ ADR、6 法令ページ実装と同 PR で起票)
- 将来の `stale-check.yml`(別 PR)が `lastVerified` を読み、90 日以上経過した法令ページに対して自動で確認 issue を立てる前提で設計する
- e-Gov・公式解説は法改正・通知改訂で更新されるため、取得日表示は政府標準利用規約「出典の記載」の実質的な精度を担保するうえで不可欠

### `/about` ページの構成予約

`/about` ページ(`src/pages/about.astro`、別 PR で作成)に以下のセクションを必須化する。

- **サイトの立場** — 「自前の法解釈は加えず、公式解説への入口を整理する」
- **引用の根拠** — 政府標準利用規約 第 2.0 版 + 著作権法 13 条 への参照
- **誤りの報告窓口** — `law@edu-evidence.org` + 24 時間以内対応の宣言

## 帰結

### 良い帰結

- 6 法令ページ実装時の判断基準が明文化される(レビューチェックリストとして使える)
- 姉妹サイト 3 つ(edu-evidence / edu-watch / edu-law)で「出典明示・直リンク・編集者意見なし・誤り報告窓口」の運用骨格が揃う
- 政府標準利用規約準拠が技術的に担保される(規約改訂時の追従ポイントが明確)
- `lastVerified` 運用予約により、stale 検知 CI(`stale-check.yml`)の地ならしができる
- 教師読者は「このサイトでは自前解釈を読まされない」という安心感を持って使える

### トレードオフ / 既知のリスク

- 「現場ではこう使われる」「裁判例ではこう判断される」等の解説型コンテンツが書けない(教師の現場便宜性とは独立)。公式解説外の現場運用は弁護士・教育委員会・各種研修の領域として明確に切り離す
- 24 時間以内対応は運営者の負荷(姉妹サイト edu-watch と同じ運用負担、休暇時の不在対応は別途検討)
- 図表転載不可のため、表現が文字中心になる(法令解説の性格上は問題なし)
- 略称併記ルールにより文章がやや長くなる(可読性とのトレードオフは初出時のみで吸収)

## 撤回 / 再検討の条件

- 政府標準利用規約が 2.1 / 3.0 等に改訂された場合(本 ADR を上書きする ADR を起票する)
- 著作権法 13 条 / 32 条の解釈に影響する判例 / 法改正が出た場合
- 文部科学省・文化庁・厚生労働省・e-Gov 運営側のいずれかから運用方針照会・是正依頼があった場合(該当箇所を一時非表示にして協議し、結果を新規 ADR 化)
- `law@edu-evidence.org` の対応体制を変更する場合(24 時間以内対応の維持可否を含む)
- 6 法令ページ実装で本 ADR の 5 要件のいずれかが運用負荷の観点から維持困難と判明した場合
