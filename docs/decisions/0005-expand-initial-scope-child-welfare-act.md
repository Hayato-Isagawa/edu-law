# 0005. 初期スコープの拡張(児童福祉法を 7 法令目として追加)

- 状態: 採用
- 日付: 2026-05-19
- 関連 PR: TBD(`content/child-welfare-act-add`)
- 関連 ADR: 0001(初期スコープ・ミラーブランド)・0003(法令コンテンツスキーマ)

## 背景

ADR 0001 では「初期スコープは 6 法令、児童福祉法は第 2 期候補」と決定していた。しかし直前 PR #32(`content(laws): expand child-abuse-prevention-act with mext notice and cfa references`)で `src/content/laws/child-abuse-prevention-act.md` を拡充した際、`## 関連法令` 節に **児童福祉法**(e-Gov 法令番号 `322AC0000000164`)を e-Gov リンクのみで追加した。

児童福祉法は児童虐待防止法と表裏一体の核法令で、以下の現場依存関係を埋める導線が無いままだった:

- **第 25 条(通告義務)** — 児童虐待防止法 第 6 条と重なる通告義務の原典
- **第 25 条の 2(要保護児童対策地域協議会 = 要対協)** — 学校が委員として参画する場
- **児童相談所** の権限・機能・運営
- **児童発達支援 / 放課後等デイサービス** — 障害のある児童の通所支援

PR #32 を通じて児童虐待 → 児童福祉法の依存関係が明確になり、現場頻度の高さ(通告義務の原典・要対協・児童相談所はすべて児童福祉法に根拠)と既存 6 法令との結節度から、初期スコープ昇格を判断する。

ADR 0001 は不変原則の下で歴史的記録として保持し、本 ADR で「7 法令目として児童福祉法を追加する」決定を独立して記録する。

## 検討した選択肢

- **A) 児童福祉法を初期スコープに昇格(7 法令目として追加)**(採用) — schema を `max(6)` → `max(7)` に拡張、`order: 7` で新規ページを起こす。現場の通告義務原典・要対協・児童相談所への直接導線が確立する。`CLAUDE.md` の第 2 期候補から児童福祉法を削除する。
- **B) 第 2 期のまま、相互リンクのみ強化** — `child-abuse-prevention-act.md` の関連法令節に児童福祉法を内部リンクで予約参照する形に留める。スコープ拡張は避けられるが、児童福祉法の独立ページが無いため通告義務(第 25 条)・要対協(第 25 条の 2)の原典導線が e-Gov 直接リンクのみになり、教員が公式解説に辿り着けない。
- **C) 児童福祉法から「教員関係章」だけ抽出した部分ページに留める** — 第 7 章(児童相談所)・第 25 条系のみを扱う限定ページ。法令単位の整合性が崩れ、ADR 0001 の「法令別ポータル」設計と齟齬が出る。

## 決定

A 案を採用する。

### 具体的な変更

- `src/content.config.ts` の `order` 制約を `.max(6)` → `.max(7)` に拡張する(1 行のみ)。
- `src/content/laws/child-welfare-act.md` を新規作成し、`order: 7` で配置する。公式解説 publisher は全て `cfa`(ADR 0003 既存登録、`src/data/publishers.ts` の `PUBLISHER_LABELS` で「こども家庭庁」にラベル解決される)。
- `CLAUDE.md` プロジェクトルートを編集する:
  - 「初期スコープ — 6 法令」→「初期スコープ — 7 法令」
  - 一覧の 7 番目に「児童福祉法」を追加
  - 「第 2 期以降の追加候補」から児童福祉法を削除

### 公式解説の選定

公式解説は全て一次源 `.go.jp` ドメイン下、こども家庭庁(cfa)の以下 4 リソースを採用する(本 PR 起票前に WebFetch で HTTP 到達性を確認済):

1. 改正児童福祉法(令和 4 年 6 月改正)案内ページ(`https://www.cfa.go.jp/policies/jidougyakutai/Revised-Child-Welfare-Act`)
2. 児童虐待に係る法令・指針等一覧(`https://www.cfa.go.jp/policies/jidougyakutai/hourei-tsuuchi`)
3. 児童虐待防止対策(政策トップ、189 ダイヤル案内、`https://www.cfa.go.jp/policies/jidougyakutai`)
4. こども家庭庁 法令ページ(`https://www.cfa.go.jp/laws`)

ADR 0003 の `eGovUrl` 正規表現(`^https://laws\.e-gov\.go\.jp/`)および `officialExplanations[].url` 正規表現(`^https://[^/]+\.go\.jp/`)を満たす。`publisher: cfa` は ADR 0003 で中央リスト管理に決定済みで、新規追加は不要。

## 帰結

### 良い帰結

- 通告義務(児童福祉法 第 25 条)・要対協(第 25 条の 2)の原典に教員が直接アクセスできる。
- 児童虐待防止法ページとの相互リンクが ADR 0001 の「法令別ポータル」設計に沿って確立する(`child-abuse-prevention-act.md` の `## 関連法令` 節は別 PR で内部リンク化を予定)。
- 公式解説 publisher が `cfa` で揃うため、出版者を跨いだ整理が不要で編集者負荷が小さい。
- schema の `max(N)` を ADR 駆動で拡張する前例ができ、第 2 期候補(教育基本法・学校保健安全法等)を昇格させる際の手順が明確になる。

### トレードオフ / 既知のリスク

- 初期スコープが ADR 0001 の想定(6 法令)から 7 法令に拡張される。後続でさらなる拡張(教育基本法・学校保健安全法等)を行う場合、毎回 ADR を起こす運用負荷が発生する。
- schema の `max(7)` は静的な数値制約で、将来 8 法令目を追加する際は再度 ADR + schema 拡張が必要になる(`order` を unique constraint に変える等の構造変更は今回は行わない、最小変更原則)。

## 撤回 / 再検討の条件

- 8 法令目を追加する場合は、本 ADR を参照しつつ新規 ADR を起こして `max(N)` を再拡張する。
- 児童福祉法ページの公式解説に厚生労働省(`kouroushou`)系の児童相談所運営指針等を追加する必要が生じた場合、本 ADR は変更せず、コンテンツ PR の判断で対応する(publisher 中央リストは ADR 0003 既存登録範囲で完結)。
- ADR 0001 の「6 法令」記述と本 ADR の「7 法令」記述が衝突するため、両 ADR を併読することを `docs/decisions/README.md` または本 ADR の参照節で読者に促す運用は別途検討する。
