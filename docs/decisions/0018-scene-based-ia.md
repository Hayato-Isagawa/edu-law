# 0018. 場面軸 IA への再編とグローバルナビへの場面レンズ追加

- 日付: 2026-06-15
- ステータス: 採択
- 関連 PR: feat/scene-based-ia

## 背景

ADR 0011 で導入した 2 入口 IA(「子供への指導・対応」「教師を守る」)は、その後 ADR 0013・0015 で両入口とも独立ページ化された。しかしこの構成は 2 つの分類軸がねじれていた。

- トップページは**目的軸**(子供 / 教師)で分岐するのに、グローバルナビは**形式軸**(法令一覧 / ガイド)で切られている。下層ページに降りると目的軸の文脈が消え、入口ページへはトップに戻らないと辿れない。
- `/protect-teachers/` と `/guides/` の「教師を守る」は中身が約 9 割重複していた(ADR 0016 が両ページ同期の運用で縛っていた)。
- `/child-guidance/` は `/laws/` の薄い部分集合だった。
- そもそも「法令か、ガイドか」は提供側の都合であって、教師の関心(困りごと=場面)ではない。

ADR 0011・0013・0015 はいずれも撤回再検討条件に「**グローバルナビでの分岐が必要なほど入口の認知が課題になった場合 → ナビ再編を別 ADR で検討する**」と予約していた。本 ADR はその正式発動である。

## 検討した選択肢

外部調査(情報アーキテクチャ設計論・日本の公的ポータル・法令情報サイト 8 例の 3 系統)を行い、3 つの軸を比較した。

### A) 目的 / 対象者軸(子供 / 教師)を主軸

Nielsen Norman Group「Audience-Based Navigation: 5 Reasons to Avoid It」が警告する**自己分類の失敗**に該当する。教師が困った瞬間、保護者クレーム・いじめ・体罰などは「子供対応」と「教師保護」の両方にまたがり、利用者がどちらの入口か即座に選べない。**不採用**。

### B) 場面 / タスク軸(いじめ / 保護者対応 / 著作権 …)を主軸(採用)

利用者(教員)はタスク志向で来る。困りごと=場面はラベルに直接マッチし、自己分類が不要。NN/g・英国 GOV.UK のタスクベース IA 原則が支持し、法テラス・こども家庭庁・消費者庁など日本の実例も第一階層に場面/対象者軸を置いている。

### C) 形式 / 主題軸(法令一覧 / ガイド)を主軸

法令名を既に知っている利用者の known-item 探索には有効だが、「どの法令を見るべきか分からない」教師の課題解決には不十分。法令情報サイト 8 例すべてで「一般向け=場面軸主 / 一次資料=索引従」の併存が成立しており、形式軸は**従の索引**として残すのが定石。

姉妹サイト EduEvidence JP は既に `/concerns/`(悩みレンズ)と戦略リスト(コンテンツレンズ)を併存させており(ADR 0015 で確認)、場面レンズの採用は family 規範への合流でもある。

## 決定

主軸=場面軸 (B)、従=法令索引 (C)、補助=「教師を守る」視点 (A) の 3 層併存とする。

1. **場面ハブ `/scenes/` を新設**(`src/pages/scenes/index.astro`、1 ページ・個別ページなし。EduEvidence `/concerns/` をミラー)。
2. **`src/data/scenes.ts` を場面定義の正本とする**。4 カテゴリ 16 場面。場面 → 法令 slug / ガイド slug の**一方向参照**(法令 `.md`・ガイド `.astro` は逆タグを持たない)。
3. **4 カテゴリ**: 子どもへの指導・対応 / 保護者・事故・ハラスメント / 自分の健康と働き方 / 身分・任用・資格。各カテゴリ 6 本以下(ADR 0016 の閾値を継承)。
4. **グローバルナビに「場面から探す」を第 1 項として追加**(ヘッダ・フッタ)。法令一覧・ガイド・サイトについては維持。
5. **トップページの 2 入口カードを場面 featured(`EntranceRow`)に置換**。法令一覧・最近の更新・公式解説 Highlights・編集方針は維持。
6. **`/child-guidance/`・`/protect-teachers/` を削除し `/scenes/` へ 301 リダイレクト**(`public/_redirects`、Cloudflare Pages)。`/child-guidance/` → `/scenes/#students`、`/protect-teachers/` → `/scenes/`。
7. **`/guides/` は「読む前の基礎＋全ガイド目録」として縮小存続**(第 2 レンズ)。個別ガイド 11 本の URL・本文は不変。
8. **自前解釈ゼロの厳守**: 教師保護系の場面はガイド経由で公式情報へ誘導し、場面に法的概念ラベルを付けない。法令本文への単純リンクに留める(ADR 0010 決定 3 を継承)。

## 帰結

### 良い帰結

- トップの主導線とグローバルナビが「場面」で一致し、下層でも文脈が保たれる
- `/protect-teachers/` と `/guides/` の重複が解消(到達点を `/scenes/` に一本化)
- 教師が困りごとから最短で関連法令・公式解説・ガイドへ到達できる
- 既存素材(child-guidance 6 場面・protect-teachers 10 ガイド)の再ラベリングで実現でき、新規コンテンツ作成・新規コンポーネント・新規 CSS はほぼゼロ

### トレードオフ / 既知のリスク

- 旧 2 ハブの 301 で SEO の一時変動の可能性(被リンク資産は 301 で引き継ぐ)
- ガイドは content collection でないため、場面ハブのガイド表示名(`scenes.ts` の `guides[].title`)を手動同期する負債(ADR 0016 の同期負債を一部継承)
- changelog 過去エントリの旧 URL リンクは `/scenes/` 系へ更新(履歴本文は不変)

## 撤回 / 再検討の条件

- いずれかのカテゴリが 6 本を超えて肥大化した場合 → カテゴリ分割を別 ADR で検討(ADR 0016 の閾値運用を継承)
- `/scenes/` と `/laws/` の重複が利用者にとって冗長と判断される場合 → 統廃合を別 ADR で検討
- 場面ラベルやカテゴリ帰属が利用者の直感に反すると判断される場合 → 帰属基準の見直しを本 ADR の改訂で扱う
