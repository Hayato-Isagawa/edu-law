# 0037. 本文のリンクをアクセント色と、背景と 3:1 以上の下線で示す

- 状態: 採用
- 日付: 2026-11-24
- 関連 ADR: edu-evidence 0049・edu-watch 0088(本文のリンクを平常時も下線とアクセント色で示す)、[ADR 0029](0029-print-stylesheet.md)

## 背景

本サイトの本文リンク(`.link-underline` と `.law-body a`)は、最初から平常時に下線を付けている。ただし色は罫線と同じ `--color-line` で、背景との比は実測で light 1.22:1、dark 1.46:1 しかなかった。リンクの文字色は地の文と同じなので、手掛かりはこの下線だけになる。公式資料への外部リンクが本サイトの機能そのものなので、見えない下線は機能の欠落にあたる。

姉妹の edu-evidence と edu-watch は本文のリンクをアクセント色にしており、本サイトだけが本文と同じ色だった。この差の理由を書いた記録は、リポの文書に見つからなかった。

## 検討した選択肢

- **文字と下線をアクセント色にする(採用)**: 下線が 3:1 を超え、姉妹サイトとそろう。手掛かりが色と下線の 2 つになる
- **下線だけ濃くする(`--color-sub`)**: 条文の文字色は変わらないが、姉妹サイトとの差が残る
- **文字はそのまま、下線だけアクセント色**: リンクの色が 1 つのリンクの中で割れる

## 決定

1. `main` の中の `.link-underline` と `.law-body a` を、文字も下線もアクセント色にする(e-Gov の本文へのリンクのように単独で置くものも含む)
2. サイトのヘッダーとフッター、および `main` の中のナビ・見出し・ヘッダーは変えない
3. 画面だけに効かせる(`@media screen`)。印刷は ADR 0029 のとおり
4. 平常時の線は 1px で、文字の色の 70%。背景との比は両テーマで 3:1 以上を保つ。線は `border-bottom` で描く。ホバーとフォーカスではこの線を消してから、2px の線を左端から右へ引く(動きを減らす設定では動かさない)。どちらも border の箱の下端に置く
5. `e2e/links-and-theme.spec.ts` が、代表ページの本文リンクの色が地の文と違うこと、線の比と引き直し、ヘッダーとフッターの下線が一括指定に戻っていないことを見る

## 帰結

- リンクの密な条文のページで、アクセント色の文字が増える
- アクセント色と本文色の比は light 2.05:1、dark 1.68:1 なので、色だけでは足りない。主な手掛かりは下線のまま
- `text-decoration` の下線と背景の線では、位置の基準(文字のベースラインと箱の下端)が違い、フォントごとにずれる。border と背景なら同じ箱なのでそろう
- 外部リンク(`inline-flex`)は、本文の中では `inline` にする。箱のままだと、折り返した題名の最後の行にしか線が付かず、行送りの分だけ文字からも離れる
- ヘッダーとフッターの下線は `text-decoration` のまま。一括指定にすると、ビルドが `underline 1px` に畳み、それを読めない Safari(26.1 以前)では消えるので、線の種類と太さを分けて書く

## 撤回 / 再検討の条件

- リンクの密なページで本文が読みにくいと分かったとき
