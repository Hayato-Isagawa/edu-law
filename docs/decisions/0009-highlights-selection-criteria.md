# 0009. Highlights セクションの選定基準と表示順

- 日付: 2026-05-20
- ステータス: 採択
- 関連 PR: feat/highlights-7-laws-coverage

## 背景

トップ「公式解説 Highlights」セクションは、所管省庁の代表的な公式解説を法令ページへの入口として並べる場である。PR #38(段階 3 = FV 整列)までの時点で同セクションは 4 件のみで、整理対象 7 法令(`CLAUDE.md`「初期スコープ」)のうち 3 法令(教育職員免許法・児童虐待防止法・個人情報保護法)に対応する公式解説がトップから可視化されていなかった。

トップ「Laws — 整理対象」が 7 件揃っているのに Highlights が 4 件のままだと、法令と代表解説のカバレッジが非対称となり、ポータルとしての一貫性を損なう。本 ADR を採択する PR で Highlights を 7 件・order 昇順に再構築する。

選定の根拠を ADR として残さないと、将来の追加・並び替えのたびに再議論となり、整合性が散逸する。

## 決定

### 選定基準(3 段、上位優先)

1. **第一基準: 教師の実務文脈への近さ**
   - 学校・教育委員会向けに発出された文書(手引き・通知・基本方針)を、法律所管機関の汎用文書(逐条解説・一般向けパンフレット)より優先する
   - 例: 児童虐待防止法は厚労省/こども家庭庁の所管だが、Highlights では文部科学省「学校・教育委員会等向け 虐待対応の手引き」を採用する

2. **第二基準: 一次源(発行機関ドメイン)限定**
   - sourceUrl は publisher の公式ドメインに限る(`mext.go.jp` / `bunka.go.jp` / `cfa.go.jp` / `mhlw.go.jp` / `laws.e-gov.go.jp` 等)
   - 二次まとめ・news・書籍紹介ページは不可(memory rule 14、edu-evidence の `docs/CONTENT_GUIDELINES.md` Rule 1.2b と整合)

3. **第三基準: `src/content/laws/{slug}.md` の `officialExplanations[0]`**
   - 各法令の laws collection で最上位に置かれた公式解説を起点として採用する
   - 法令ページと Highlights で代表解説が乖離しないよう、laws collection が事実上の起点となる

### 表示順

法令 `order` 昇順。現状の 7 法令スコープでは:

| order | 法令 | publisher | badge |
|------:|------|-----------|-------|
| 1 | 学校教育法 | 文部科学省 | mext |
| 2 | 教育職員免許法 | 文部科学省 | mext |
| 3 | いじめ防止対策推進法 | 文部科学省 | mext |
| 4 | 児童虐待防止法 | 文部科学省 | mext |
| 5 | 著作権法 | 文化庁 | bunkacho |
| 6 | 個人情報保護法 | 文部科学省 | mext |
| 7 | 児童福祉法 | こども家庭庁 | cfa |

法令と 1:1 対応を維持し、各法令から代表解説を 1 件のみ採用する。

### スコープ(定常状態)

7 法令完全網羅(各法令 1 件、計 7 件)を Highlights セクションの定常状態とする。

- 将来法令を追加した場合は、対応する代表解説を 1 件追加し `order` に従って挿入する
- 既存 7 法令の代表解説を差し替える場合は、laws collection 側の `officialExplanations` 並び順を先に変更する(本 ADR 第三基準が起点を laws に置いているため)

## なぜこの 3 段にしたか

- 第一基準を最上位に置く理由: EduLaw JP は教師実務向けポータルであり、現場で実際に参照される文書を Highlights に出すべき。法律所管の網羅性は法令ページ側の `officialExplanations` 配列で確保されているため、Highlights は実務距離を最優先する
- 第二基準で一次源に限る理由: edu-evidence PR #136 の教科担任制 RCT 訂正(memory rule 14)で、二次まとめ経由の引用が連鎖的に誤情報を生む事例を経験している。Highlights は外部向けの「公式解説の代表」を名乗るため、ドメイン由来の正確性を妥協できない
- 第三基準で laws collection を起点に縛る理由: Highlights と法令ページで代表解説が食い違うと、読者が法令ページに遷移したときに「Highlights で見た文書はどこ?」となる。laws collection を SSoT とする

## トレードオフ — publisher が mext 偏重(7 件中 5 件)

- 結果: 学校教育法・教員免許法・いじめ防止法・児童虐待防止法・個人情報保護法の 5 件が mext、著作権法のみ bunkacho、児童福祉法のみ cfa
- 受容理由: 教師実務文脈の文書は事実上 mext.go.jp 中心であり、第一基準を優先するとこの偏りは自然な帰結
- 視覚的多様性を理由に第一基準を歪めない(badge 多様化のために教師実務距離が遠い文書を採用しない)

## 不採用案

### badge 多様性を選定基準に含める

publisher が複数になるよう恣意的に選ぶと、教師実務文脈から逸れた解説を Highlights に出すことになるため不採用。Highlights の本義(実務に近い代表入口)を毀損する。

### 法令ごとに複数件採用する

「重要解説」と「補足解説」を 1 法令から 2 件以上採用する案は、Highlights セクションが肥大化し「代表」性を失うため不採用。複数解説は法令ページ側で網羅する(役割分担)。

## 撤回再検討条件

- 法令スコープが大幅拡張(例: 7 → 12 法令)し、Highlights セクションが視覚的に冗長化した場合(セクション分割・代表 1 件選抜方式への移行を別 ADR で検討)
- 教師実務距離より「法律横断比較」のニーズが優勢になった場合(第一基準の改定)
- 一次源公式解説の見つからない法令を追加した場合(第二基準の例外規定追加)

## スコープ外

- 各 Highlights カードの視覚デザイン(別 ADR で扱う領域)
- 法令ページ側 `officialExplanations` の並び順規約(本 ADR は laws collection を SSoT として参照するのみ。並び順自体は別 ADR / 別 PR で扱う)
- Sister Sites セクションの表示順(関連 ADR 0007)
